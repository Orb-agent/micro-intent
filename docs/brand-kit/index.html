06 / Build consistently

Implementation contract

Attention is context

A soft grayscale patch can suggest the target. Voice or selection confirms it. Gaze alone never authorizes a write.

Actions stay explicit

Show exactly what will change. Confirm before writes. Display Done only after success. Offer Undo only when it works.

Small, accessible UI

44px targets, clear focus, editable transcript, polite status announcements, and static reduced-motion states.

Use tokens.css, tokens.json, OrbsIndicator.tsx, orb-motion.css and README.md from the developer bundle. Reference sizes: 64px hero / 20px inline orb. Hero specimens use the exact 64px preset; the pill uses the exact 20px preset.
